# VayuPress — Required Mailboxes

Every `@vayupress.com` address referenced anywhere in this repository, grouped by
purpose. Create these on your own VayuMail server (VayuOS → Accounts). Addresses
that only receive can be **aliases** onto a shared mailbox; the ones that also
send (e.g. `noreply@`, `releases@`) are best as real mailboxes with their own
signing identity.

> Scope note: the **VayuMail-Mobile** app repository defines **no** email
> addresses of its own — it is a mail client. Its in-app "Support" and "Privacy"
> links point at the addresses below (`support@`, `privacy@`). So there are **no
> separate mailboxes to create for the mobile repo**; it shares this list.
