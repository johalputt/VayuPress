# VayuPress — security contact (RFC 9116)
#
# THE DATE BELOW IS THE DATE THAT GETS SERVED. It used to be a placeholder,
# rewritten at publish time by .github/workflows/deploy-site.yml, which ran daily
# so the file could never go stale. vayupress.com is now served from a VayuPress
# install instead of GitHub Pages, that workflow is gone, and
# scripts/build-selfhosted-site.sh copies this tree verbatim into the uploaded
# bundle. Nothing rewrites it any more.
#
# So it is checked instead: scripts/check-security-txt.py fails CI once the file
# is within 45 days of expiring. Push the date out when that fires. An expired
# security.txt is worse than none — scanners report it as the finding it was
# meant to prevent.
#
# An Encryption: field was appended by that same removed step, and only when the
# VayuPGP Web Key Directory actually answered, because a key URL that 404s is
# worse than none: a reporter who cannot fetch the key sends the report in
# cleartext. Nothing probes it now, so no Encryption: line is published. Add one
# by hand ONLY after confirming the WKD URL returns 200, and remove it if that
# ever stops being true.
