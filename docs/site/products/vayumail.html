Your own sovereign PGP mail server

SMTP send + receive, IMAP and POP3, RFC-6376 DKIM signing and direct-to-MX delivery — a real mail server for your domain, with automatic MX / SPF / DKIM / DMARC records and live DNS health checks. Mail never leaves your server unencrypted to a third party.

  • Send & receive from your own domain
  • DKIM-signed, direct-to-MX with STARTTLS
  • IMAP + POP3 for any client (Thunderbird, K-9…)
  • Automatic MX / SPF / DKIM / DMARC + DNS health
  • Native PGP: keys per account, published via WKD
  • Official Android app — connect in one scan
