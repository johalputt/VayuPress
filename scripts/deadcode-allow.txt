# deadcode baseline — see scripts/deadcode-gate.sh

# Each line below is a function unreachable from the program entrypoints, as
# reported by golang.org/x/tools/cmd/deadcode ("<file>: unreachable func:
# <name>", line/col stripped so it survives edits). The CI gate fails only on
# an entry NOT listed here, so new dead code is blocked. Removing an entry is
# always welcome; refresh with:  scripts/deadcode-gate.sh --update
#
# Known groups, so a reader knows why each is still here:
#  - internal/sandbox, plugins.RegisterSubprocess, vcb.Load*Manifest: the
#    out-of-process plugin runtime. It is built and tested, but no production
#    path loads a plugin into it yet.
#  - internal/vayushield: Solve (the reference proof-of-work solver; clients
#    solve in JS) and calibrate.BiasedForTest are test-suite entry points;
#    fingerprint.NewStore/FromClientHello capture only when TLS terminates
#    in-process, and today nginx terminates it; VerdictFrom is kept as API.
#  - internal/vayuflow: Schedule.String and ImplementedActions, used by tests
#    to hold implementations and capabilities against each other.
#
